## 2024-06-10 - Adding variant primary to main action buttons in Gradio
**Learning:** In Gradio interfaces with multiple buttons placed side-by-side (like Run and Clear), setting the main action button to `variant='primary'` establishes clear visual hierarchy and prevents accidental clicks on secondary actions.
**Action:** Always assign `variant='primary'` to main action buttons in Gradio when they are placed near secondary buttons.
