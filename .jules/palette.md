## 2024-05-18 - Improve Gradio Primary Actions
**Learning:** In Gradio applications, primary action buttons (like "Run" or "Submit") do not visually stand out from secondary buttons (like "Clear") by default, which can be confusing for users. Additionally, users often expect to be able to submit text inputs (like pasting a code or typing a request) by pressing Enter. By default, multi-line textboxes can become awkwardly large when users paste single-line tokens.
**Action:** Use `variant="primary"` on primary `gr.Button` elements (like `run_button` and `submit_auth_button`) to differentiate them. Bind `.submit()` events to `gr.Textbox` inputs to allow Enter-key submissions where appropriate. Use `max_lines=1` on textboxes intended for pasting long tokens (like auth codes) to prevent vertical stretching.
