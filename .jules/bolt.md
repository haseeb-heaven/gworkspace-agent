## 2024-06-12 - Performance optimization using Tuples for startswith and endswith
**Learning:** Checking prefixes or suffixes using generator expressions like `any(val.startswith(p) for p in prefixes)` or `any(val.endswith(s) for s in suffixes)` is significantly slower than using tuples directly: `val.startswith(prefixes)`. Passing a tuple to these string methods is implemented in C and evaluates much faster. This specific codebase architecture frequently relies on checking paths or ids with multiple prefixes/suffixes, making it a good candidate for this micro-optimization.
**Action:** Replace `any(path.endswith(s) for s in singular_suffixes)` and `any(val_str.startswith(prefix) for prefix in prefixes)` with tuple-based checks. Always evaluate if this micro-optimization is applicable without sacrificing code readability.
