## 2026-07-14 - [Sentinel Fix shell=os.name == 'nt']\n**Vulnerability:** subprocess.run was called with shell=True on Windows because of os.name == 'nt' check.\n**Learning:** Command Injection vulnerability can happen even if we just execute a binary like sys.executable. Windows does not strictly require shell=True to execute binaries.\n**Prevention:** When invoking subprocess.run with a command list (e.g., executing Python modules or scripts), explicitly pass shell=False across all platforms (including Windows) to prevent Command Injection vulnerabilities and avoid Bandit B602 alerts.
