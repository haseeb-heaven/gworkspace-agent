## 2024-10-24 - Primary Actions in Gradio UI
**Learning:** Adding the `variant="primary"` attribute to Gradio buttons clarifies the visual hierarchy for users and emphasizes the main call-to-actions, preventing confusion with secondary actions like clearing forms or regenerating URLs.
**Action:** Always ensure that core functional buttons in forms (like Submit, Run, Authenticate) use `variant="primary"`, while secondary or destructive actions remain default or use `variant="secondary"`.
