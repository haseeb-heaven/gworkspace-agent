## 2024-09-20 - Add primary variants to main action buttons
**Learning:** Using `variant="primary"` on primary `gr.Button` elements significantly improves the micro-UX by visually distinguishing the main calls-to-action (like "Run" and "Authenticate") from secondary actions (like "Clear").
**Action:** Apply `variant="primary"` to primary action buttons across Gradio applications to guide user interaction and improve visual hierarchy.
